## 🆘 Troubleshooting

### If Notion import fails:
1. Try copy-paste method instead
2. Ensure file is saved as `.md` extension
3. Check file encoding (should be UTF-8)
4. Try breaking into smaller sections

### If formatting looks wrong:
1. Use Notion's built-in formatting tools
2. Adjust table column widths
3. Fix code block languages
4. Re-apply heading levels

### If tables don't render:
1. Notion should auto-convert markdown tables
2. If not, copy table data and use "Insert > Table"
3. Manually recreate simple tables
